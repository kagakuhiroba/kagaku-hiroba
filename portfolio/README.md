# sumi channel Portfolio

フォトグラファー / ビデオグラファー「sumi channel」のポートフォリオサイトです。
白・青・オレンジを基調とした、明るくポップなデザインの1ページ構成サイトです。

## セクション構成

- Hero: キャッチコピーと導線
- About: 自己紹介
- Skills: スキル一覧
- Works: 作品・実績（カテゴリ絞り込み付き。画像は準備中のためプレースホルダー表示）
- Contact: 問い合わせ導線・SNSリンク

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
